# 🚀 Biswadeep's Personal Portfolio 🚀

Welcome to my personal portfolio website! This project showcases my skills, projects, and experience as a software developer. It's built with modern web technologies and designed to be a clean, fast, and responsive user experience.

## ✨ Features

*   **Modern & Responsive Design:** A clean and modern UI that looks great on all devices.
*   **Interactive UI:** Engaging animations and effects to create a dynamic user experience.
*   **Project Showcase:** A dedicated section to highlight my projects and skills.
*   **Downloadable Resume:** An easily accessible and downloadable version of my resume.
*   **Contact Form:** A functional contact form for easy communication.

## 🛠️ Tech Stack

*   **Framework:** React with Vite
*   **Language:** TypeScript
*   **Styling:** Tailwind CSS with shadcn/ui
*   **Routing:** React Router
*   **Deployment:** Vercel

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

*   Node.js (v18 or later)
*   npm or yarn

### Installation

1.  Clone the repo
    ```sh
    git clone https://github.com/Cingrix/Biswadeep-portfolio.git
    ```
2.  Install NPM packages
    ```sh
    npm install
    ```
3.  Start the development server
    ```sh
    npm run dev
    ```

## 📦 Deployment

This project is deployed on Vercel. The `vercel.json` file in the root of the project is configured for a Vite application. Any push to the `main` branch will trigger a new deployment.
